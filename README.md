## Income Tax Calculation

This is a project for displaying the tax amount for income of all individual working persons ( resident or non-resident ) less than 80 years of age . The details of this project encompasses the Default Tax Regime u/s 115BAC ( 1A ) of Government Of India .

## Technologies Involved 

* **HTML** - Structure of the Website .
* **CSS** - Style and background of website . 
* **JAVASCRIPT** - Conditions of Tax Calculation .

## Reference Datas

This project encompasses the official tax calculation methodology of INCOME TAX INDIA OFFICIAL controlled by GOVERNMENT OF INDIA . One thing is for Rs.5000001 and above I did not added the Surcharge of Tax Calculation .

## Core Concepts

This project contains the concept of ELSE-IF LADDER in JAVASCRIPT file and basic HTML and CSS elements are involved .
